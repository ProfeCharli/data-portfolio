# 📱 TikTok Project - Course 1: Foundations of Data Science (Inspect and Analyze Data)

## 📊 Project Overview / Resumen del Proyecto
This project marks the first phase of the TikTok project as part of the **Google Advanced Data Analytics Professional Certificate**. The primary goal is to conduct an initial Exploratory Data Analysis (EDA) on TikTok's dataset to understand its structure, inspect data types, investigate key variables, and uncover engagement trends between claims and opinions.

Este proyecto forma parte de la primera fase del caso práctico de TikTok en el certificado profesional de Google. Su objetivo principal es realizar un Análisis Exploratorio de Datos (EDA) inicial para comprender la estructura del dataset, inspeccionar tipos de datos, investigar variables clave y revelar tendencias de engagement entre reclamaciones (*claims*) y opiniones (*opinions*).

## 🔍 Key Findings & Insights / Hallazgos Clave
* **Dataset Composition:** The dataset contains 19,382 observations, evenly split between claims and opinions (~50% each).
* **Engagement & Claim Status:** Videos labeled as *claims* receive significantly higher view, like, share, and comment counts compared to *opinions*.
* **Author Ban Status Correlation:** Videos posted by banned authors or authors under review show drastically higher engagement levels (views, likes, shares) than those posted by active authors.
* **Engagement Rates:** While banned authors accumulate higher raw numbers, analyzing engagement *per view* reveals that claim status strongly dictates how users interact with content once viewed.
