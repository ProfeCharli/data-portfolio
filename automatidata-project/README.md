# 🚖 Automatidata - Exploratory Data Analysis & Insights

## 📊 Project Overview / Resumen del Proyecto
This project is part of the **Google Advanced Data Analytics Professional Certificate**. The objective is to analyze trip data for **New York City Taxi and Limousine Commission (TLC)** (a fictional transportation/taxi consulting client) to clean datasets, uncover operational patterns, handle outliers, and provide actionable insights regarding rider behavior and fare structures.

Este proyecto forma parte del certificado profesional de Google. Su objetivo es analizar los datos de viajes de  la Comisión de Taxis y Limusinas de Nueva York (TLC) para limpiar conjuntos de datos, descubrir patrones operativos, manejar valores atípicos y ofrecer recomendaciones basadas en el comportamiento de los usuarios y las tarifas.

* **Language:** Python 🐍
* **Environment:** Jupyter Notebooks, VS Code

* **Data Visualization:** Matplotlib, Seaborn
* **Version Control:** Git & GitHub

---

## 📈 Key Analysis & Steps / Análisis Clave y Fases
1. **Data Inspection & Cleaning:** Inspected data types, handled missing values, and checked for duplicates to ensure data integrity.
2. **Exploratory Data Analysis (EDA):** Analyzed the distribution of variables such as `trip_distance`, `fare_amount`, and payment types.
3. **Outlier Detection:** Identified and evaluated extreme values (using descriptive statistics and visualizations) to understand their impact on the dataset.
4. **Insights Generation:** Formulated key findings regarding trip lengths, high-value routes, and payment preferences.
